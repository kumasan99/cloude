## 1. 広告（WonderKEA）の学び — 失敗ではありません

数字を見ると、広告のクリエイティブとしては成功しています。

| 指標 | WonderKEA（広告） | オーガニック長尺の中央値 |
|---|---|---|
| 再生回数 | 11,060 | 176 |
| インプレッションCTR | 5.89% | 3.78% |
| 視聴維持率 | 58.5%（8分の動画で平均4分47秒） | 24.9% |
| 総再生時間 | 884時間 | — |
| 獲得登録者 | +3人 | — |

8分の動画を平均4分47秒見られています。11,060人にリーチし、合計884時間ぶんの接触を作りました。認知の「量」だけを見れば、この1本がチャンネル全体の累計再生の10%を作っています。

**失敗したのは、見た人の行き先が無かったことです。**

- 登録者は+3人だけ（3,687再生に1人）。オーガニック長尺の325再生/人に比べて11分の1の効率
- 最後まで見た人が次にどこへ行くかが、終了画面にも概要欄の先頭にも設計されていなかった
- 「WonderKEA」という事業所名は、視聴者にとって初めて聞く固有名詞。覚えて帰るフックが無い

→ 広告の再開を検討するのは、4章の受け皿（終了画面・再生リスト・概要欄の出口）を整えてから。今の状態で回すのは、穴の開いたバケツに水を注ぐのと同じです。

## 2. 「認知」を目的にするなら、旗を1つに決める

### 認知はリーチではなく「反復接触」で作られる

名前を覚えてもらうには同じ人が複数回接触する必要があり、1回の接触ではほぼ記憶に残りません。今のチャンネルの数字は、この「1回接触」で止まっていることを示しています。

- ショートは月3万再生。リーチの量は足りている
- しかしショートは2,324再生に1人しか登録しない＝見た人がほぼ戻ってこない
- 広告は11,060再生で+3人＝3,687再生に1人

つまり「知られていない」のではなく「見られたけれど覚えられていない」状態です。

### データが示す答え：「くまくま社長」

2026年4月以降の全動画を、タイトルに「社長」が入っているかで分けました。

| | 「社長」あり | 「社長」なし | 差 |
|---|---|---|---|
| ショート | 中央値 2,031（5本） | 中央値 1,012（21本） | 2.0倍 |
| 長尺 | 中央値 327（11本） | 中央値 150（31本） | 2.2倍 |

長尺とショートの両方で同じ倍率の差が出ています。ショートの上位4本のうち3本がタイトルに「社長」を含み、うち2本は「くまくま社長」と明記しています。

※ ショート側はサンプル5本と少ないため断定はしません。長尺側は11本対31本で同じ傾向が出ているため偶然である可能性は低いと判断していますが、9月に検証枠を設けて確認します（6章）。

### 提案：名前を減らす

現在、視聴者が触れる固有名詞が多すぎます（ReSow / ワンダーフレンズ / WonderKEA / ワンダーステップ / 彦三 / クマクマワーク / くまくま社長 / くまはち・くまみつ / ぺこラジ / KOREKARA手帳）。

- **旗（覚えてもらう対象）＝「くまくま社長」** ← データが最も強く支持
- 会社名（ReSow / ワンダーフレンズ）は旗のうしろに置く
- 事業所名（WonderKEA / ワンダーステップ / 彦三）はタイトルから外す。視聴者にとって意味のない固有名詞で、クリック率を下げるだけ

やること：今後の全動画のタイトルに「くまくま社長」または「社長」を入れる。

## 3. KPIの再定義（目的＝認知に合わせて）

前回の「長尺1本の公開28日再生 = 1,000」は維持します（社長からいただいた目標であり、認知の土台にもなるため）。ただし認知が目的なら、これは手段の指標であって、認知そのものを測る指標を上に置く必要があります。

**第1層：認知そのもの（最終目的）**

| 指標 | どこで見るか | 現状 | 90日後の目標 |
|---|---|---|---|
| 月間ユニーク視聴者数 | Studio → アナリティクス → 概要 | 未取得 | 現状の2倍 |
| リピート視聴者の割合 | Studio → 視聴者 → リピーター/新しい視聴者 | 未取得 | リピーター比率を上げる |
| 指名検索 | Studio → リーチ → トラフィックソース → YouTube検索 → 検索キーワード | 未取得 | 「くまくま社長」が上位に入る |

この3つは今回のCSVに含まれていません。Studioの画面で見えるのでスクリーンショットが必要です。

**第2層：認知を作る力（メガホが毎週追う）**

| 指標 | 現状 | 目標 |
|---|---|---|
| 長尺1本の公開28日再生 | 中央値 約150 | 1,000 |
| チャンネル登録者数の増加 | 月+5〜10 | 月+30 |
| 長尺CTR | 中央値 3.78% | 5.0%以上 |
| 長尺の視聴維持率 | 中央値 24.9% | 35%以上 |

**第3層：認知の先の成果（四半期で見る）**

| 出口 | 指標 |
|---|---|
| 採用 | Wantedlyのプロフィール閲覧数・応募数 |
| 書籍 | 『もう無理』の販売数・Amazonランキング |
| 利用者 | LINE登録数・見学/相談の問い合わせ数 |

登録者数を第2層に置くのは、認知が目的でも登録が「もう一度会いたい」という意思表示であり、反復接触を自動化する唯一の仕組みだからです。

## 4. 【手順書】再生リスト・終了画面・カード

3つとも無料で、撮影も編集も不要です。

### 4-1. それぞれ何なのか

**再生リスト（プレイリスト）**：動画をテーマごとにまとめたアルバム。1本見終わると次が自動再生される。再生リスト自体も検索結果や関連動画に出る。1人に2本・3本と続けて見てもらう＝反復接触で、今のチャンネルに最も足りていないもの。

**終了画面**：動画の最後5〜20秒に画面へ重ねて出る「次の動画」と「チャンネル登録」のボタン。最後まで見た人＝一番濃い視聴者の行き先を決められる唯一の場所。空白だとYouTubeが選んだ他社の動画が表示される。

**カード**：再生中に画面右上へ小さく出る案内。効果は終了画面より小さく、優先度は3番目。

**注意**：YouTubeショートは仕様上、終了画面・カードに対応していません。ショートの導線は固定コメントと概要欄1行目だけです（4-5）。

### 4-2. 再生リストの作り方（約30分）

1. YouTube Studio（https://studio.youtube.com ）を開く
2. 左メニュー「コンテンツ」
3. 上部タブ「再生リスト」
4. 右上「新しい再生リスト」
5. タイトルを入力、公開設定を「公開」にして作成
6. 作成した再生リストを開き「動画を追加」から既存動画を追加
7. 並び順はドラッグで変更。1本目に一番強い動画を置く

| 再生リスト名 | 1本目に置く動画 | 何本入るか |
|---|---|---|
| くまくま社長のお悩み相談（最優先） | 「特性を持った人からの悩み事相談！」（327再生） | 悩み相談系すべて。ショートも入れる |
| くまくまぺこぺこラジオ 全話 | 第1回（266再生） | 21本 |
| 障害福祉の現場を見てみる | 「水引製造にガチ挑戦」（356再生） | 作業紹介・施設外就労・彦三など |
| 会社の中の人たち | 「広報2人のリアルな1日」（509再生） | 密着・入社式・日常 |
| はたらく人向け｜就労支援ってなに？ | 「就労支援事業 社長が徹底解説」（登録者+11人と最多） | 制度解説系 |

再生リストのタイトルにも「くまくま社長」を入れると認知に効きます。1つの動画は複数の再生リストに入れられます。

### 4-3. 終了画面の設定（1本目に10分、2本目以降は各30秒）

**1本目（テンプレートになる動画）**

1. Studio →「コンテンツ」→ 動画をクリック
2. 左メニュー最下部「終了画面」
3. 「要素を追加」から2つ追加
   - 「動画」→ 特定の動画を選択 → 同じ再生リストの次に見せたい動画
   - 「登録」→ チャンネル登録ボタン
4. タイムラインで表示時間を動画の最後20秒に設定
5. 配置は「左に動画、右に登録ボタン」が定番
6. 「保存」

**2本目以降**

1. 動画の「終了画面」を開く
2. 「動画からインポート」（または「テンプレートを適用」）
3. 1本目で作った動画を選ぶ → 設定がコピーされる
4. 「動画」要素の指定先だけ、その動画に合う次の1本に変更
5. 保存

1本30秒。長尺42本でも30分かかりません。

**注意点**

- 終了画面は動画の長さが25秒以上ないと設定できない
- 終了画面が出ている間その部分の映像は隠れる。最後20秒に大事な話や顔が映っている場合は少し手前で締めるか、要素の配置をずらす
- ショートには設定できない

### 4-4. カードの設定（優先度3番目）

1. 動画を開き、左メニュー「カード」
2. 「カードを追加」→「動画」または「再生リスト」
3. 関連する話題が出てくる瞬間にタイミングを合わせる
4. 保存

1本につき1枚で十分。冒頭には置かない（離脱を招く）。中盤〜後半が定石。

### 4-5. ショートの導線

既存のショート26本すべてに以下2つ。1本あたり1分、合計30分ほど。

**固定コメント**：自分のショートのコメント欄に `フル版はこちら→ https://youtu.be/xxxxx` を投稿し、そのコメントの「⋮」→「固定」。

**概要欄の1行目**：説明文の1行目に長尺のURL。2行目以降は現状のまま。

**再生リストに追加**：ショートも再生リストに入れられる。悩み相談系のショートは全部「くまくま社長のお悩み相談」へ。

## 5. 認知の「受け皿」を出口別に整理する

認知の先に採用・書籍・利用者の3つの出口があることが確定しました。現在の概要欄はHP・X・Instagram・LINE・Wantedlyが全部同じ重さで並んでいます。全部載っている＝どれも押されない、ということです。

**動画の内容ごとに、出口を1つだけ強調する**

| 動画のタイプ | 強調する出口1つ | 概要欄の書き方 |
|---|---|---|
| お悩み相談・生きづらさ系 | LINE | 「一人で抱えている方へ。相談窓口はこちら→」 |
| 書籍・KOREKARA手帳系 | 書籍/手帳の購入ページ | 「『もう無理』と思ったときに読む本→」 |
| 密着・入社式・会社の日常 | Wantedly | 「こんな職場で働いてみませんか→」 |
| 現場・作業紹介 | HP（事業所案内） | 「見学・体験のお問い合わせはこちら→」 |

残りのリンクはその下に小さくまとめれば十分。「1動画1出口」が原則です。
